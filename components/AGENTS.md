# Interface instructions

Root instructions apply. Keep workers' actions direct: Today, Plan and More on phones; clear labels, readable cards and reachable save controls.

Use `WorkspaceRuntimeProvider` for all data access. Public showcase components must not load Supabase sessions or call private APIs. Keep record fields available through the essentials form and clearly named detail sections. Hidden validation failures must open the section and make the error reachable.

Never treat a UI status change as an inspection approval without the shared validation/evidence. Keep failed saves and conflicts visible. Human users must be able to inspect and correct the same records an external agent edits. Do not add decorative automation buttons without a working implementation.

After changes, verify phone/desktop rendering and a real save/error path appropriate to the change. Preserve the supplied logo unchanged.
